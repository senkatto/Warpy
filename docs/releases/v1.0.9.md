# Warpy 1.0.9

Обновление для Android и Windows доступно через «Проверить обновления» в Warpy.

## Android

- При потере сети Warpy показывает «Ожидание сети» и сбрасывает таймер подключения. При появлении сети приложение само восстанавливает VPN.
- Исправлена обработка смены маршрута при переходе между Wi‑Fi и мобильной сетью, в том числе когда адрес или шлюз меняется на том же Wi‑Fi.
- Страница входа в Wi‑Fi и перенаправление больше не считаются успешной проверкой интернета. Warpy проверяет наличие VPN-интерфейса и ожидаемый ответ по HTTPS.
- Запоздавшее состояние службы больше не возвращает удалённые профили и не подменяет выбранный профиль. В исключения можно добавлять доменные зоны, например `ru`.

## Windows

- При подключении и восстановлении Warpy проверяет трафик через системный VPN-интерфейс и DNS. Это устраняет ложный статус «Подключено», когда прокси отвечает, а системный туннель не работает.
- Исправлен переход на IPv4 в браузере при недоступности IPv6. Это затрагивало загрузку некоторых видео и изображений YouTube.

## Файлы обновления

- Android 1.0.9, код сборки 26 — `Warpy-Android.apk`.
- Windows 1.0.9, x64 — `Warpy-Windows.exe` и `latest.json` с подписью установщика для встроенного обновления.
