# Политика безопасности Warpy

Warpy обрабатывает учётные данные VPN-профилей и сетевой трафик устройства.
Не публикуйте в открытых задачах рабочие ссылки профилей, пароли, UUID, приватные
ключи, хранилища ключей и журналы без предварительного удаления личных данных.

## Как сообщить об уязвимости

Создайте приватное обращение через **Security Advisories** этого репозитория.
Если приватные обращения недоступны, свяжитесь с сопровождающими проекта напрямую
до публикации информации об уязвимости.

В сообщении укажите:

- затронутую версию Warpy и платформу;
- версию Android или Windows;
- последовательность действий для воспроизведения;
- ожидаемое и фактическое поведение;
- обезличенный журнал или скриншот, если он помогает воспроизвести проблему.

Не прикладывайте рабочие данные VPN-профиля. Замените адреса серверов, UUID, пароли,
ключи и ссылки подписок безопасными примерами.

Проблемы, возникающие только на конкретном VPN-сервере или у отдельного провайдера,
следует сначала направлять владельцу соответствующей инфраструктуры.

# Warpy Security Policy

Warpy handles VPN profile credentials and device network traffic. Do not post
working profile links, passwords, UUIDs, private keys, keystores, or unredacted
logs in public issues.

## Reporting a vulnerability

Create a private report through this repository's **Security Advisories** section.
If private advisories are unavailable, contact the project maintainers directly
before publishing information about the vulnerability.

Include:

- the affected Warpy version and platform;
- the Android or Windows version;
- clear reproduction steps;
- the expected and actual behavior;
- a redacted log or screenshot when it helps reproduce the issue.

Do not include working VPN profile credentials. Replace server addresses, UUIDs,
passwords, keys, and subscription URLs with safe examples.

Issues that only affect a particular VPN server or provider should first be reported
to the owner of that infrastructure.
