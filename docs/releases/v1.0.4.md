# Warpy 1.0.4

## Исправлено

- Новые версии автоматически обнаруживаются, даже если Warpy уже открыт.
- Проверка выполняется при возврате в приложение и после восстановления сети.
- Фоновая проверка запускается каждые 15 минут вместо шести часов.
- Плашка найденного обновления больше не исчезает во время повторной проверки.
- Параллельные проверки обновлений на Android исключены.

[Полный список изменений](https://github.com/senkatto/Warpy/compare/v1.0.3...v1.0.4)
