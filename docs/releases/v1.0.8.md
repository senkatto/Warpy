# Warpy 1.0.8

Единый релиз для Android и Windows. Обновление доступно через «Проверить обновления» в приложении.

## Android

- Исправлена привязка соединений VPN при переходе между Wi-Fi и мобильным интернетом.
- При смене сети сбрасываются старые транспортные сессии, включая Hysteria/QUIC.
- Восстановление продолжает ждать появления сети, даже если уведомление Android было пропущено при отмене запуска. Отключение VPN пользователем отменяет ожидание.
- Устранены конкурирующие обновления состояния сети; выбор интерфейса дожидается необходимых данных Android.

## Windows

- Исключённые приложения направляются напрямую до проверки протокола и фильтрации трафика. Это исправляет порядок обработки исключений, в том числе для qBittorrent.

## Обновление

- Android: версия 1.0.8, код сборки 25; файл `Warpy-Android.apk`.
- Windows: версия 1.0.8; файл `Warpy-Windows.exe` и подписанные данные встроенного обновления.
- Обновление устанавливается поверх текущей версии с сохранением настроек.

Автоматические проверки Android пройдены. Реальное переключение Wi-Fi ↔ мобильная сеть на телефоне для этого исправления пока не проверено.
