# Warpy 1.0.6

Единый релиз для Android и Windows.

- Добавлена проверка доступности профилей и отображение задержки до подключения.
- Исправлена проверка профилей на Android во время активного VPN.
- Повышена стабильность VLESS, NaiveProxy и восстановления туннеля при смене сети.
- Исправлены переключение профилей и отмена зависшего подключения.
- Выбранный профиль на Android отмечается зеленой рамкой протокола без смещения элементов.
- Исправлены обнаружение обновлений и фоновая проверка новой версии.
